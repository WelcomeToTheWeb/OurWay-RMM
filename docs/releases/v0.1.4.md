# OurWay RMM v0.1.4 Release Notes

**Release date:** 2026-09-24

v0.1.4 is a CI + installer hardening release. It fixes the one-click
installer for non-root users (GitHub Actions runners, desktop users),
makes the webhook delivery tests deterministic, and cleans up the last
CI failures that were blocking green builds on main.

## Installer

- **Non-root installs work**: the shell installer (`scripts/install.sh`)
  now installs to `~/.local/bin` and `~/.config/ourway-rmm` when run as
  a regular user, and creates a user systemd unit at
  `~/.config/systemd/user/ourway-rmm-agent.service` (with
  `default.target`). Root installs are unchanged.

## CI / Tests

- **Webhook delivery tests deterministic**: added `waitJournal()` that
  blocks until all published events are journaled before sweeping,
  eliminating the async gap that caused CI-only flakes. Tests now count
  unique deliveries instead of exact counts, tolerating retry-based
  duplicates.
- **Postgres scratch DB names quoted**: `CREATE DATABASE`/`DROP DATABASE`
  now double-quote the hyphenated scratch DB name in all 19 affected
  call sites.
- **Migration count not hardcoded**: five live tests that asserted
  exactly 11 migrations now count the `.sql` files in
  `server/migrations` instead.

## What's Next

0.1.5 will focus on completing existing subsystems that don't fully
work: scheduled reports that never execute, notification policy routing
that's dead code, and staged/canary agent rollouts.
