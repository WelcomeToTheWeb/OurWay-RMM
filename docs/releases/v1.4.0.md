# OurWay RMM v1.4.0 Release Notes

**Release date:** 2026-09-24

v1.4.0 is a hardening + follow-through release: remote sessions are now
audited, hardened, and actually render in the browser; the 1.3.0 rebrand is
completed on Windows (service + install dirs), and the remaining rebrand
regressions are fixed.

## Remote Session

- **Viewer renders again (critical fix)**: the server emits *named* SSE
  events (`event: frame`) with snake_case payloads; the viewer now listens
  with `addEventListener` for `hello`/`frame`/`status`/`goodbye` and reads
  the matching fields, so frames actually display.
- **Audit trail**: every session event (`session.started`,
  `session.stream_opened`, `session.stream_closed`, `session.stopped`) is
  published on the flow bus (`ourway-rmm.events.session`) — who had remote
  access to which device, and when.
- **Lifecycle safety**: sessions auto-close when the last viewer
  disconnects, a background sweep reaps stale file-pull transfers and idle
  device state, and `agent_offline` is surfaced to viewers (the session is
  kept and resumes on reconnect). Closing a session clears its latest frame
  so a stale frame can't be replayed to a new session.
- **Hardening**: session streams open with a short-lived,
  device+session+operator-bound stream ticket (the operator JWT no longer
  appears in the stream URL); session IDs are cryptographically random; all
  session routes are tenant-scoped to the operator's clients; agent input
  is gated to the live session with Win/Meta-key combos blocked (no remote
  `Win+L`/`Win+R`/`Win+X`).

## Windows: rebrand follow-through

- The Windows service is now `OurWayRMMAgent` (was `RmmWayAgent`); installs
  go to `C:\Program Files\OurWay RMM` / `%LOCALAPPDATA%\OurWayRMM` (was
  `RMMWay` / `RmmWay`).
- Re-running `scripts/install.ps1` on a pre-1.3.0 machine stops + deletes
  the legacy service and carries the old install dir over (agent.env +
  logs), so an upgrade can't leave two agents running or orphan the
  bootstrap config.

## Fixed

- gRPC `Enroll` rejected with 401 (hand-typed method path used a hyphen
  where the generated proto uses an underscore; now uses the generated
  constant)
- Self-heal escalation panicked on ticket creation (nil context passed to
  the Postgres store)
- Broken `go test` fixture and load-test module after the rebrand
- Remote session test suite committed (it was untracked)
- Stray signer build artifact removed and gitignored
- Operator guide bootstrap API response documented accurately

## Changed

- Version constants aligned across Makefile, server default, env example,
  and compose pins
- Release asset inventory check now includes the windows-arm64 agent
  binary and its SBOM
